# 《万国觉醒·统帅远征》游戏资源分析

> 依据 `mini-game-builder` 铁律 5 输出。**实现时必须与本文件逐项对齐**：配色取值、字号、间距、命名、音效触发点一一对应；后续改动需同步更新本文件。
> 美术基准：万国觉醒官方 APK（`com.lilithgames.rok.offical.cn` v1.1.13.72）内提取的 UI 资源（见 `src/static/game/wgjx/`）。

## 0. 项目定位

- **名称**：《万国觉醒·统帅远征》（代号 `ZBCX-WGJX`）
- **形态**：横屏 H5 小游戏（uni-app 容器 + Phaser 3 引擎，复用 `prjtmpl` 模板）
- **后端**：cherry（Go Actor 框架），提供登录 / 提交分数 / 排行榜 / 存档
- **美术/音乐/UI 一致性**：风格锚定万国觉醒（写实历史·鎏金史诗），与 APK 提取资源保持一致

## 1. 玩法 / 关卡 / 计分 / 胜负（先定后做）

### 1.1 核心循环

玩家作为执政官，在 1280×720 横屏战场的**左下方主城**派出部队，沿行军路线进发，攻克**右上方敌方据点**。连击积累「统帅值」，满槽触发「集结」范围攻击。单局**限时 60 秒**。

### 1.2 操作

- **点击己方主城**：循环切换出征兵种（步兵 / 骑兵 / 弓兵）
- **点击 / 拖拽敌方据点**：派出当前兵种，单位从主城沿路线进发
- **连击**：连续 3 次成功派兵触发 ×2；「集结」按钮消耗统帅值，一次派 3 路
- **返回**：退出回大厅

### 1.3 计分

| 事件 | 分值 |
|---|---|
| 击破敌方据点 | +120 |
| 击败敌方单位 | +15 |
| 连击倍率 | ×1 ~ ×3 |
| 通关存活主城奖励 | +200 |

**目标分**：1000。

### 1.4 胜负

- **胜利**：时间结束且得分 ≥ 目标分；或清空全部敌方据点
- **失败**：主城耐久 ≤ 0（被敌方反击耗尽）

### 1.5 关卡

单局即一关；难度随连击与据点再生速率递增。后续可扩展多关（数据驱动）。

## 2. 横屏与适配

- **设计分辨率**：1280×720
- **Phaser**：`type: AUTO`，`scale.mode: FIT`，`autoCenter: CENTER_BOTH`
- **pages.json**：`pageOrientation: "landscape"`；竖屏设备显示旋转提示（复用 `ddz.vue` 的 `.ddz-rotate` 机制）
- **index.html**：`viewport` 配合 CSS 横屏

## 5. 音乐音效

- **说明**：万国觉醒原版音效随 AssetBundle 加密下发，无法提取（同 `ddz-audio.js` 结论），故以 **Web Audio 实时合成**等效音色，保持「史诗战歌」听感。
- **清单**：

| 音效 | 触发点 | 合成方式 |
|---|---|---|
| BGM | 进入对局 / 退出 | 循环史诗和声（低频铜管 + 弦乐 pad） |
| 派兵 `send` | 点击派出 | 木质叩击 + 短促号角 |
| 得分 `score` | 击破据点 / 击败敌军 | 明亮上行五声 |
| 击败 `hit` | 单位交战 | 冲击 + 噪声爆发 |
| 集结 `rally` | 触发集结 | 三段递进号角 |
| 胜利 `win` | 通关 | 大调琶音 + 金币声 |
| 失败 `lose` | 主城失守 | 下行小调 |
| 倒计时 `tick` | 最后 10 秒每秒 | 滴答 |

- **格式**：Web Audio 合成（无需音频文件）；若引入音频文件则用 `ogg`（优先）/ `mp3` 兜底，采样 44.1k。

## 6. UI 效果

- **按钮**：鎏金渐变 + 白描边 + 按下缩放 0.95 + 顶部高光（`drawButton` 同构）
- **HUD**：顶部信息栏（得分 / 时间 / 统帅值条 / 兵种指示），深棕木条底
- **弹窗**：淡入 + 缩放（300ms）
- **场景过渡**：淡入淡出 300ms
- **连击提示**：鎏金徽章弹跳
- **字体**：主标题 `Arial Black`，正文 `sans-serif`，描边雪白 / 深棕
- **交互**：按钮 `useHandCursor`，禁用态 `alpha 0.5`

## 7. 与实现的一致性约定

1. 调色板集中在 `wgjx-theme.js` 的 `COLOR` 对象；改色只动此处，并同步本文件第 3 节。
2. 所有图元由 Graphics 程序化绘制，配色取自上表；改皮肤同步更新第 3 / 4 / 6 节。
3. 音效触发点见第 5 节，实现（`wgjx-audio.js`）须一一对应。
4. 场景结构沿用 `ddz-game.js` 的 `createXxxScene(Phaser, hooks)` 工厂范式；网络沿用 `ddz-net.js` 的 JSON 行协议（`{"cmd","data"}` + `\n`）。
